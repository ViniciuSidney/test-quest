# v0.5 — Embaralhamento de alternativas

## Objetivo

Permitir que cada nova sessão apresente as alternativas objetivas em uma ordem diferente sem alterar sua identidade, gabarito, resposta oficial ou marcações auxiliares.

## Funcionamento

A ordem é definida uma única vez durante `createActiveSession`. O array já reordenado é salvo dentro da sessão, portanto atualizar a página ou continuar pela Home não executa um novo sorteio.

```text
Importação: A, B, C, D, E
Sessão:    C, A, E, B, D
Recarga:   C, A, E, B, D
```

As letras mostradas na tela são calculadas pela posição atual. A alternativa mantém o mesmo `id` e a correção utiliza `respostaCorretaId`.

## Opções registradas

```js
opcoes: {
  mostrarGabaritoFinal: true,
  embaralharQuestoes: false,
  embaralharAlternativas: true
}
```

## Regras

- somente questões objetivas têm alternativas reordenadas;
- a questão importada não é alterada diretamente;
- o sorteio evita devolver exatamente a ordem original;
- respostas e marcadores permanecem vinculados ao ID;
- uma sessão restaurada preserva a ordem existente;
- uma nova sessão realiza um novo sorteio;
- com a opção desligada, a ordem original é preservada.

## Resultado e exportações

A letra exportada corresponde à posição visual daquela sessão. O texto da alternativa é incluído para evitar ambiguidade:

```text
Sua resposta: C) Texto da alternativa
Resposta correta: A) Texto da alternativa correta
```

## Orientação para autores

Explicações devem descrever o conteúdo correto, sem depender da letra original. Em vez de “a alternativa B está correta”, use “a opção que emprega corretamente os termos está correta”.

## Compatibilidade

O esquema permanece na versão 4. Sessões anteriores não possuem `embaralharAlternativas`, portanto o valor é normalizado como `false`. Não há reordenação retroativa de sessões já existentes.

## Critério de aprovação

A etapa é aprovada quando gabarito, resposta, marcadores, resultado e TXT permanecem coerentes depois do embaralhamento, salvamento e restauração.
