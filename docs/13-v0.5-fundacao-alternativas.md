# v0.5 — Fundação de alternativas e respostas

## Objetivo

Desacoplar a identidade das alternativas das letras mostradas na tela. Essa base é necessária para embaralhar alternativas, adicionar novos tipos objetivos e criar sessões de revisão sem perder correção, marcações ou respostas.

## Mudança central

Na v0.4, a letra era ao mesmo tempo posição, identidade e resposta. Na v0.5, cada alternativa possui um ID estável e a letra passa a ser apenas sua posição visual atual.

```text
Antes: resposta = "B"
Agora: resposta = "alt-ould7l-b"
Tela: B)
```

## Compatibilidade

- sessões com esquema 3 são convertidas automaticamente para o esquema 4;
- respostas antigas em letras são resolvidas pela chave original;
- marcações auxiliares também são migradas;
- o campo `correta` permanece temporariamente disponível;
- o resultado e os relatórios continuam mostrando letras.

## Critério de aprovação

A etapa é aprovada quando uma sessão da v0.4 pode ser migrada, continuada e finalizada sem diferença visual, enquanto o JSON salvo registra alternativas e respostas pelo novo modelo.

## Próxima etapa

Implementar o embaralhamento de alternativas usando apenas a reordenação do array. IDs, resposta correta, respostas do usuário e marcadores não devem ser alterados.
